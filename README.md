# Homebrew Tap for PiDesk

Official Homebrew Cask tap for [PiDesk](https://github.com/RaiderWang/pidesk) — native GUI desktop companion for `oh-my-pi` (`omp`).

## Installation

```bash
brew install --cask raiderwang/tap/pidesk
```

Or tap first:

```bash
brew tap raiderwang/tap
brew install --cask pidesk
```

## Update

```bash
brew upgrade --cask pidesk
```
