# Homebrew Tap

Official Homebrew Cask tap by [@RaiderWang](https://github.com/RaiderWang).

## Available Casks

### ⚡ [Power Editor](https://github.com/RaiderWang/power-editor)
High-performance cross-platform text editor optimized for large files (100 MB+ / GB+).

```bash
brew install --cask raiderwang/tap/power-editor
```

### 🖥️ [PiDesk](https://github.com/RaiderWang/pidesk)
Native GUI desktop companion for `oh-my-pi` (`omp`).

```bash
brew install --cask raiderwang/tap/pidesk
```

---

## Tap & Upgrades

You can also tap this repository once:

```bash
brew tap raiderwang/tap
```

And install or upgrade casks directly:

```bash
# Install
brew install --cask power-editor
brew install --cask pidesk

# Upgrade
brew upgrade --cask power-editor
brew upgrade --cask pidesk
```
